1. HELP OUTPUT
──────────────────────────────────────────────────────────────────

$ python epub_to_pdf.py --help

usage: epub_to_pdf.py [-h] [-v] epub_file [pdf_file]

Convert EPUB files to PDF format

positional arguments:
  epub_file      Path to the input EPUB file
  pdf_file       Path to the output PDF file (optional, defaults to <epub_name>.pdf)

options:
  -h, --help     show this help message and exit
  -v, --version  show program's version number and exit

Examples:
  epub_to_pdf.py book.epub book.pdf       Convert book.epub to book.pdf
  epub_to_pdf.py book.epub                Convert book.epub to book.pdf (auto-name)
  epub_to_pdf.py input.epub output.pdf    Convert with specific names

Requirements:
  pip install ebooklib lxml weasyprint

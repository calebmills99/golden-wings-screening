🚀 QUICK START
═══════════════════════════════════════════════════════════════════

Option 1: CLOUDFLARE PAGES (Recommended - Best Performance)
───────────────────────────────────────────────────────────────────
1. Add GitHub Secrets (Settings → Secrets → Actions):
   • CLOUDFLARE_API_TOKEN (from dash.cloudflare.com → API Tokens)
   • CLOUDFLARE_ACCOUNT_ID (from Cloudflare dashboard URL)

2. Push to main:
   $ git add .
   $ git commit -m "Enable CI/CD"
   $ git push origin main

3. Configure domain in Cloudflare Pages dashboard

Result: https://gwingz.com (global CDN, PR previews)

───────────────────────────────────────────────────────────────────

Option 2: GITHUB PAGES (Simpler - No Secrets)
───────────────────────────────────────────────────────────────────
1. Enable in Settings → Pages:
   • Source: "GitHub Actions"
   • Custom domain: gwingz.com (optional)

2. Push to main:
   $ git add .
   $ git commit -m "Enable CI/CD"
   $ git push origin main

Result: https://gwingz.com or gwingz-studio.github.io/gwingz-screening

───────────────────────────────────────────────────────────────────

Option 3: USE SETUP WIZARD
───────────────────────────────────────────────────────────────────
$ ./.github/setup-deployment.sh

Guides you through:
  • Choosing deployment method
  • Disabling unused workflows
  • Getting required secrets
  • Next steps

═══════════════════════════════════════════════════════════════════

Cloudflare Pages:
  ✓ Push to main → Production deployment
  ✓ Pull request → Preview deployment
  ✓ Manual → Actions tab → Run workflow

GitHub Pages:
  ✓ Push to main → Production deployment
  ✓ Manual → Actions tab → Run workflow

Build Validation:
  ✓ Pull request to main → Validate only
  ✓ Push to other branches → Validate only

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

Build fails:
  → Check Actions logs
  → Test locally: npm run build
  → Verify package.json scripts exist

Cloudflare fails:
  → Verify secrets are set correctly
  → Check API token permissions
  → Ensure account ID is correct

GitHub Pages 404:
  → Settings → Pages → Source: "GitHub Actions"
  → Wait 5-10 minutes for deployment
  → Check DNS configuration

Site broken:
  → Check browser console for errors
  → Verify CSS built: docs/css/styles.css
  → Verify images copied: docs/images/
  → Test form submission to Worker
